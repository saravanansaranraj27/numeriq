How to use Function Plotter

Compare supported mathematical functions on a responsive coordinate plane.

  1. Choose a preset function from each dropdown.
  2. Add or remove function rows to compare curves.
  3. Adjust the range slider to zoom the visible x-domain.
Example

Compare sin(x), cos(x) and x²; trigonometric functions use radians.
